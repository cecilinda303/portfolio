🐾 Petshop API

Back-end Projeto individual Kotlin Spring Boot
🐾

Descrição do Projeto

API REST desenvolvida em Kotlin + Spring Boot para gerenciamento de um petshop. O sistema resolve o problema do controle manual de cadastros, oferecendo cadastro, listagem, atualização e remoção de pets e seus tutores, com busca parcial por nome, validação automática de dados e autenticação JWT.

Tecnologias Utilizadas

Kotlin Spring Boot 3.x Spring Web Spring Data JPA Spring Security JWT Bean Validation H2 Database Gradle

Minha Participação

  • 🐾 Desenvolvimento completo do backend (projeto individual)
  • 📦 Modelagem das entidades Pet e Tutor com JPA
  • 🔌 Criação dos endpoints REST (GET, POST, PUT, DELETE)
  • 🔐 Implementação de autenticação com JWT via Spring Security
  • ✅ Validação de dados de entrada com Bean Validation
  • 🌐 Configuração de CORS para integração com o frontend
  • 🏗️ Arquitetura em camadas (Entity, Repository, Service, Controller, DTO, Mapper)
  • 🔎 Implementação de busca parcial por nome (case-insensitive)

Arquitetura

O projeto segue arquitetura em camadas bem definidas:

  • Entidades — classes JPA (Pet, Tutor)
  • Repositórios — interfaces JpaRepository com queries JPQL
  • Serviços — regras de negócio e CRUD
  • Controllers — endpoints REST
  • DTOs / Mappers — conversão Entity ↔ DTO
  • Exception Handler — tratamento global de erros
  • Config — configurações do Spring Security e CORS
