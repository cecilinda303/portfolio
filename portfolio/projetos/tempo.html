App de Previsão do Tempo

Front-end Projeto pessoal API REST
🌦️

Descrição do Projeto

Aplicação web que consulta o clima em tempo real de qualquer cidade, exibindo temperatura, condições do tempo e ícone ilustrativo. Consome uma API pública de previsão do tempo e apresenta os dados de forma amigável.

Tecnologias Utilizadas

JavaScript Fetch API API REST CSS3

Minha Participação

  • Estruturação da interface HTML/CSS
  • Consumo da API de clima com fetch
  • Tratamento de erros e loading
  • Exibição dinâmica dos dados no DOM
