## 📌 Projetos em destaque

### 🎓 Carteirinha Digital — FATEC Itaquera
Sistema em **TypeScript** desenvolvido em equipe para substituir a carteirinha física dos alunos.
Minha participação incluiu implementação de **2FA**, **cadastro em massa** via CSV/TXT/PDF,
**upload de fotos com aprovação**, correção de bugs e integração entre branches.

🔗 [Ver repositório](https://github.com/Carteirinha-Digital-Fatec-Itaquera)

### 🐾 Petshop API
API REST em **Kotlin + Spring Boot** para gerenciamento de pets e tutores.
Inclui autenticação **JWT** com Spring Security, validação de dados com Bean Validation,
busca parcial por nome, arquitetura em camadas (Entity, Repository, Service, Controller, DTO, Mapper)
e banco H2 em memória.

**Tecnologias:** Kotlin, Spring Boot 3.x, Spring Web, Spring Data JPA, Spring Security, JWT, H2, Gradle

🔗 [Ver repositório](https://github.com/cecilinda303/petshop)

### 📱 Petshop Frontend
Aplicativo cliente em **Kotlin Multiplatform + Compose Multiplatform** que consome a Petshop API.
Roda nas plataformas **Android, Web e Desktop**, compartilhando lógica de negócio e interface
entre elas. Utiliza **Ktor Client** para requisições HTTP e **Kotlinx Serialization** para os dados.

**Tecnologias:** Kotlin Multiplatform, Compose Multiplatform, Ktor Client, Kotlinx Serialization, Coroutines

🔗 [Ver repositório](https://github.com/cecilinda303/petshop-front)
