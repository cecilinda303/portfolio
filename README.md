## 🎀 Sobre o projeto

Site de portfólio com identidade visual própria (clean/rosé), tema claro e escuro,
animações suaves e alguns easter eggs de Pokémon pra deixar com a minha cara. 💅

## ✨ Funcionalidades

- 🎨 Identidade visual personalizada (tema rosé + dark mode)
- 📸 Foto e informações pessoais
- 🎓 Formação acadêmica
- 💼 Experiência profissional
- 📚 Cursos de extensão e idiomas
- 📁 Portfólio com cards para cada projeto
- 📄 Página individual para cada projeto
- 🌙 Alternância entre modo claro e escuro (salva preferência)
- ✨ Animações suaves ao rolar a página
- 📱 Layout responsivo (funciona em celular e desktop)

## 📌 Projetos em destaque

### 🎓 Carteirinha Digital — FATEC Itaquera
Sistema em **TypeScript** desenvolvido em equipe para substituir a carteirinha física dos alunos.
Minha participação incluiu implementação de **2FA**, **cadastro em massa** via CSV/TXT/PDF,
**upload de fotos com aprovação** e integração entre branches.

🔗 [Ver repositório](https://github.com/Carteirinha-Digital-Fatec-Itaquera)
